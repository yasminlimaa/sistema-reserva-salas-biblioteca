# Serviço de Chaves — demo funcional local

API REST em Node.js 24/Fastify com PostgreSQL no Supabase. Atende as telas de **Serviço de Chaves / Claviculário** (`ServicoChaves.jsx`), **Modal de Histórico de Chaves** (`HistoricoChavesModal.jsx`) e a coluna de situação da chave na **Gestão de Reservas** (`GestaoReservas.jsx`).

## Comandos para iniciar e testar

```bash
cd codigo/backend/chaves
nvm use
npm install
npm test
```

Porta padrão: `http://127.0.0.1:3004`.
